SENTINEL: Storage & Usage Governance Dashboard
==============================================

QUICK START FOR NON-TECHNICAL USERS:
------------------------------------
1. Double-click "START.bat"
2. The dashboard will open automatically in your browser
3. When done, close the black terminal window

REQUIREMENTS:
-------------
- Windows PC
- Python installed (should already be on most Motorola laptops)
- Modern web browser (Chrome, Edge, Firefox)

TROUBLESHOOTING:
----------------
If START.bat doesn't work:
1. Open Command Prompt in this folder
2. Type: python -m http.server 8000
3. Open your browser to: http://localhost:8000

WHAT THIS DASHBOARD SHOWS:
---------------------------
- Storage capacity vs usage across agencies
- Camera deployment vs authorized licenses
- Contract expiration alerts
- Health status indicators (Red/Yellow/Green)
